# The World Folded Into One Building

An interactive digital atlas of the Temple of All Religions (Вселенский храм) in Kazan, Russia.

**Live site:** https://pritidipadas.github.io/The-Temple-of-All-Religions/

## What's inside

- A documentary film (7 min 25 s), which plays straight through, with chapter shortcuts: [download the MP4](film/The_World_Folded_Into_One_Building.mp4)
- An interactive globe that links each hall to its homeland, with great-circle distances from the temple
- Every hall shown with its video, photographs and text
- An animation room, a timeline, a full photo gallery, and myths and facts
- A comparison of multi-faith buildings around the world
- A quiz and word list in English and Bangla

## Running it locally

It's a static site with no build step. Serve the folder with any web server, for example:

```
python3 -m http.server
```

Then open http://localhost:8000.

Map data: Natural Earth. Footage and photographs: project collection.
